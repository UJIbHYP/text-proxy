# textproxy

Сервис, который превращает любую веб-страницу в **чистый текст**: по переданному
URL он скачивает страницу, убирает HTML-теги и панели, и отдаёт только
содержимое — готовое к копированию или обработке программами.

Например, страница со списком http://-ссылок превращается в текстовый список
этих ссылок — по одной на строку, без HTML-мусора.

---

## Быстрый старт

Всё, что нужно — это один бинарник (готовые сборки лежат в `dist/`):

```bash
./textproxy            # запускает сервис на порту 8080
```

Затем в другом терминале:

```bash
curl "http://localhost:8080/?url=https://example.com/"
```

В ответ придёт обычный текст (`text/plain`): заголовок страницы, абзацы, ссылки
— всё подряд, без тегов и скриптов.

Проверить, что сервис жив: `curl http://localhost:8080/healthz` → `ok`.

---

## Что вы получите на выходе

**Вход:** URL любой страницы + (опционально) язык перевода.

**Выход:** чистый текст страницы. Пример реального результата — страница
со списком 

Каждая ссылка — на отдельной строке, без HTML-обёртки. Такой текст можно
сохранить в файл и использовать напрямую:

```bash
curl -s "http://localhost:8080/?url=https://example.com/" > content.txt
```

---

## Как пользоваться

### Вариант 1. HTTP-сервис

Запустите `textproxy` и отправляйте запросы:

```
GET /?url=<URL>&lang=<lang>
```

| Параметр | Обязательный | По умолчанию | Описание |
|----------|--------------|--------------|----------|
| `url`    | да | — | адрес страницы (обязательно `http://` или `https://`) |
| `lang`   | нет | `de-de` | язык перевода, формат `xx-xx` |

Примеры:

```bash
curl "http://localhost:8080/?url=https://example.com/"
curl "http://localhost:8080/?url=https://example.com/&lang=en-en"
```

Если открыть тот же адрес в браузере — увидите тот же текст.

**Коды ошибок:**

| Код | Что значит |
|-----|------------|
| `400` | не указан `url`, или это не абсолютный `http(s)` адрес |
| `405` | запрос не `GET` |
| `502` | не удалось получить страницу (сеть, страница недоступна, ответ не текстовый) |

### Вариант 2. CLI-скрипт (без сервера)

Тот же результат без запуска сервиса — скрипт `get_url.sh`:

```bash
./get_url.sh "https://example.com/" de-de
```

Скрипт скачает страницу и сохранит рядом два файла:

- `full_page.html` — страница целиком;
- `content.txt` — чистый текст без HTML-тегов.

Нужны `curl`, `wget`, `awk` и `python3` (есть практически в любом Linux).

## Запуск и настройка

### Порт

По умолчанию сервис слушает порт `8080`. Сменить порт:

```bash
./textproxy -port 9000          # флагом
PORT=9000 ./textproxy           # или переменной окружения
```

### Где взять бинарник

| Файл в `dist/` | Где запускать |
|----------------|---------------|
| `textproxy-linux-amd64` | обычные серверы и ПК (x86-64) |
| `textproxy-linux-arm64` | Raspberry Pi, VPS на ARM, Termux |
| `textproxy-linux-arm` | 32-битный ARM |
| `textproxy-android-arm64` | нативный Android (запуск через `adb shell`, нужен root) |

Бинарники статически слинкованы — просто скопируйте файл на нужную машину и
запустите, никаких зависимостей не нужно.

### Собрать из исходников

Требуется Go 1.26. Код использует только стандартную библиотеку:

```bash
./build_linux.sh                # соберёт все варианты под Linux в dist/
go build -o textproxy .         # или просто один бинарник
```

Для Android-бинарника нужен Android NDK:
`ANDROID_NDK_HOME=/path/to/android-ndk ./build_android.sh`

> Подсказка: для Termux подойдёт обычный `textproxy-linux-arm64` — в Termux
> сеть работает без специальной сборки.

## Как это работает (коротко)

1. Сервис получает у Яндекс Переводчика «прокси-префикс» (один раз на 5 минут).
2. Целевой URL приклеивается к префиксу, и страница скачивается через
   прокси-обёртку turbopages.
3. Из HTML вырезается содержимое страницы (без панелей обёртки), снимаются
   теги и раскодируются HTML-сущности (`&amp;` → `&`).

Если прокси-префикс протух — сервис сам получит новый и повторит запрос.

---

## Ограничения

- Сервис зависит от Rндекс Переводчика (`translated.turb0.org`): если он
  недоступен или изменил формат страницы, извлечение может перестать работать.
- Отдаётся только текст: страницы больше 10 МБ отклоняются, бинарные ответы
  (картинки, PDF, видео) — тоже.
- Извлечение текста эвристическое — на очень сложной разметке возможны
  небольшие артефакты.

## Структура проекта (для разработчиков)

| Файл | Назначение |
|------|------------|
| `main.go` | HTTP-сервер и обработчики запросов |
| `proxy.go` | получение прокси-префикса, скачивание страницы |
| `extract.go` | извлечение чистого текста из HTML |
| `get_url.sh` | CLI-версия (без сервера) |
| `build_linux.sh`, `build_android.sh` | сборка бинарников |
| `main.py` | устаревший исследовательский скрипт (не используется) |
